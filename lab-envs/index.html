    Why these environments are new

    Each task asks the agent to make a material that hits a target property, such as the temperature at which its magnetic order sets in. In most agent environments the model can read the state it acts on, such as a web page or a repository. Here the state is a simulated sample the agent never sees, so each episode is partially observable (a POMDP). Damp samples, leaking seals and furnaces that run hot show up only in its measurements. The wet bench is hands-on lab work. The dry + wet chain adds computer simulation and a Linux desktop. Each claim below opens on the step of a recorded run that shows it.
